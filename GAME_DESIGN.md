# AG Cute Blocks — Game Design Baseline

## Audience
Primary-school children. The game must feel like play, never like homework or a teaching app.

## Core principles
1. Fun first.
2. Very low learning curve, high creative ceiling.
3. Cute / cozy / bright original visual identity.
4. Building-first creative sandbox.
5. Rich building catalogue without a complicated interface.
6. Safe private multiplayer; no public stranger chat.
7. Mistakes are cheap: undo/redo and easy removal.
8. Creativity and problem-solving emerge naturally from play.

## Planned building catalogue
Target 150–250+ base objects/materials plus color/material variants: terrain, woods, stone, brick, concrete, glass, roofs, doors, windows, stairs, rails, fences, columns, floors, walls, roads, water, plants, lights, furniture, kitchen, bathroom, toys, signs and decorative objects.

## Interaction roadmap
Mobile movement/look, place/remove, jump, material catalogue, favorites/recent/search, rotate, undo/redo, line/wall/fill tools, copy, interactive doors/lights/switches, toys/vehicles, local world save, PWA/offline cache, then private two-player rooms and realtime synchronization.

## V0.1 checkpoint
A playable mobile 3D foundation with touch movement/look, jumping, block placement/removal, a small colorful material palette and an original cute sample environment.
